Автоматизированное тестирование веб-приложения для размещения объявлений
📋 О проекте
Проект содержит автоматизированные тесты для веб-приложения размещения объявлений. Тесты покрывают ключевые сценарии работы с пользователями и объявлениями.

🎯 Тестируемый функционал
1. Авторизация и выход из системы
Успешная авторизация - вход существующего пользователя

Выход из системы - корректное завершение сессии

2. Регистрация пользователей
Успешная регистрация - создание нового аккаунта

Регистрация с невалидным email - валидация email-адреса

Регистрация существующего пользователя - обработка дубликатов

3. Работа с объявлениями
Создание объявления неавторизованным пользователем - проверка доступа

Создание объявления авторизованным пользователем - полный цикл размещения

🛠 Технологический стек
Python 3.14+ - язык программирования

Pytest - фреймворк для тестирования

Selenium WebDriver - автоматизация браузера

ChromeDriver - драйвер для браузера Chrome

🔧 Установка и настройка
1. Установка зависимостей
bash
pip install -r requirements.txt
2. Установка ChromeDriver
Убедитесь, что версия ChromeDriver соответствует установленному Chrome.

3. Запуск тестов
Запуск всех тестов:

bash
python -m pytest
Запуск конкретного тестового файла:

bash
python -m pytest test_authorization.py
Запуск с детализированным выводом:

bash
python -m pytest -v
Запуск с генерацией отчета:

bash
python -m pytest --html=report.html
